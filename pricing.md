# Pricing — Catalogue Scraper package

Fixed-price packages delivering a ready-to-run scraper as source code plus
docs. Prices in VND, one-time.

## Tiers

| Tier | Scope | Price | Delivery |
|---|---|---|---|
| **Basic** | 1 site, up to 3 listing pages per run | 800.000đ | 2-3 working days |
| **Standard** | 3 sites + scheduled recurring runs | 1.600.000đ | 3-5 working days |
| **Custom** | Larger scope, extra fields, JS-heavy sites | Quote per order | Agreed per order |

## What's included (every tier)

- Working scraper source code + per-site adapters
- Offline test suite (`pytest`, no network needed)
- README with install and run instructions
- 1 revision round after delivery

## Scope notes

- Public pages only — no login, no captcha bypass, no personal data
- Sites whose structure changes may need a re-adapted adapter (covered by
  the included revision where it is a small fix)

## Payment terms

- 50% upfront to start work; remaining 50% on delivery
- Engagements expected to run longer than 2 months are billed in milestones
  agreed upfront
