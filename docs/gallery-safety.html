Safety by default

Built to stay inside the rules

Every scraper I write ships with these limits on. You can read them in the config file.
Robots.txt
Checked before the first request. If the site disallows the path, the run stops and says so. It does not try to work around it.
Rate limit
About 1 request per second by default, with jitter. Configurable, but the default is the polite one.
Retries
Backoff on 429 and 5xx only. A 403 is treated as a stop signal, not something to hammer through.
Scope
Public business listings only. No login walls, no CAPTCHA solving, no personal data about individuals.
# config.yaml - the limits are visible, not hidden in code
request_delay: 1.0          # seconds between requests
respect_robots_txt: true     # stop when the site says no
max_retries: 3            # only for 429 / 5xx
retry_backoff: 2.0         # exponential
max_pages: 50
on_parse_error: "log_and_skip"   # never silently drop a page
user_agent: "MyScraper/1.0 (+contact)"
Public listing data only. About 1 request per second, robots.txt respected.
Business and company records only - no personal data about individuals.
